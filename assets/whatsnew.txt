Continuum 0.35
--------------

Initial public release

Cumulative changes from Subspace 1.34/1.35 to Continuum .35 follows:

-Bug Fixes

Main Menu/Interface
* No longer crashes when incorrect directory server address is used

Game
* All current cheats and cheat programs no longer function (no more 
  cheaters!)
* Lag turrets impossible to create
* Using F1 Help List in spec mode will not kick you out of game (from 
  v1.35 only)
* "Ball-warping" (using mouse to click portal icon while holding ball) 
  is now impossible
* SysReq key no longer induces lag
* Unspeccing on the ball no longer lags the ball
* "Fastbombing" is no longer possible in any form (nothing you do can 
  override the bomb fire delay, as defined in each zone's server 
  settings)
* Client doesn't crash with more than 8 balls in an arena
* No longer crashes with small player spawn radius or small green/ball 
  spawn radius
* Still bombs don't turn into mines
* In zones where you spawn where you die, you can no longer jump 
  through a wall before respawning (also, you cannot go through walls 
  by attaching to a just-killed turret)
* When you are attached, low energy reading is displayed next to your 
  ship
* ?go (Public 1) will actually take you to the public arena called 
  (Public 1)
* Afterburner sound no longer carries over to spectator mode
* Rocket sound no longer continues during respawn delay
* Clock would sometimes show 12:xx AM when it was PM
* ?status no longer crashes game, even if there are bad settings
* Using a new goal.wa2 actually works
* In previous versions, if you had bouncy bombs and fired one while 
  not moving, it would be a normal bomb - this no longer occurs
* Overflow bug that sometimes causes flag carriers to be psuedo 
  invincible (with certain settings) is fixed
* Prizeweight:Quickcharge setting and Prizeweight:Recharge setting
  were reversed in old client
* Getting placed in safe zone while alt-tabbed did not activate safe 
  zone timer: fixed

Visuals
* Using F4 to spectate a pair of players no longer messes up freq 
  colors
* Alt-tabbing in and out of game no longer screws up banners
* No weird "reappear and warp" behavior when killing alt-tabbed 
  clients
* No more screwed up psychedelic in-game colors
* When spectating on a freq, player name colors are always correct 
  for their freq (the freq you are spectating has yellow names and 
  enemies have blue names)
* When spectating a freq, that freq's flags are yellow, and enemy flags 
  are blue
* If you have no bullets, but you have bombs with shrapnel, the shrapnel 
  would be invisible to other people in older clients, but it would 
  still do damage.  Continuum now displays that shrapnel

Chat
* Client always closes and saves log file if you quit before closing 
  log (sometimes it didn't)
* You can now use the same %macro more than once in the same line

Chat Window
* Chat display shows correct text formatting (some messages would look 
  formatted in-game, but screwed up in chat window in old client)
* Certain characters and text would sometimes show up as strange symbols 
  in chat display, this is fixed


-New Features

Main Menu/Interface
* Auto-transfers your options/settings/preferences from any previous 
  installations of Subspace
* Profiles let you store individualized settings for different names and 
  different zones (including macros, key definitions, resolution, chat 
  channels, etc.)
* Ability to reconfigure your keyboard layout so you can choose what keys
  do what (you can have a key to activate chat mode, letting you use 
  letters for actions too).  Up to three different keys can be used per 
  combination per action (example: ctrl + alt + R could be repel)
* More macros allowed
* Updating/Adding zones is streamlined
* Built-in graphical trace utility to check your ping and packetloss to 
  any zone
* Quicker and more accurate ping updates on Zone List
* You can have as many zones as you want on Zone List
* Zone List is color-coded to indicate on and off-line zones
* Automatic weblinks to your favorite zones' websites
* Can create desktop links to open Continuum with different profiles
* Can store multiple directory server address, Client will cycle through 
  all of them
* Graphical ping display for zones in zone list that shows last 7 pings


Game
* Entering game and changing arenas takes less time
* Updated F1 help list to reflect new commands
* When spectating player, you can see new info on their antiwarp, stealth, 
  xradar, and cloak status
* Printscreen is disabled - no longer kicks you from game (no more lamers 
  escaping sure death), but it does let you take screenshots in-game! (puts
  screenshot to clipboard, paste to paint program)
* When greening, game will report what percentage of max equipment that you 
  have (like your last green put you at 55% of your Max Top Speed)
* Supports more than 10 (Public) arenas
* Can set/change ?sound volume in game
* Game announces when "Player left arena"
* No CD check (from v1.34 only)
* You can optionally use xradar from spec
* In F2 Player List display, you can see what freq you are on, and how many 
  are on your freq (the little red-lettered heading in Player List did not 
  appear above your freq in old client)
* Scroll Lock will also take screenshots in-game, as many as you want, 
  auto-saving them to screenshot1.bmp, etc.
* ?status displays your speed/thrust/recharge as percentage of current / 
  maximum instead of percentage of current - initial / maximum (no more 0% 
  recharge even when you have recharge)
* ?flags no longer returns location of flags, only names and numbers (flag 
  locations now accessible through *flags - and is left to each zone to decide 
  who can access that info)
* Supports new sysop /*warpto command
* Can load new *.wa2 or *.bm2 files while game is running

Visuals
* Better framerate and smoother animation and movement on most machines (fps 
  wont go over monitor refresh rate - so if SS says 300 fps now, but your 
  monitor can only do a refresh rate of 80 fps, new client will only show what 
  you are actually doing)
* Ability to play in Windowed mode at any resolution that your system supports 
  (you can check email, etc. while still watching game in a window - also, no 
  sounds when SS is not the active window)
* Option to make radar and level map (ALT) transparent (you can see game 
  behind radar)
* Option to make F2 Player List transparent (you can see game behind F2 List)
* If player you are spectating can see mines on radar, you can see mines too
* Decoys of Flag carriers and PowerBall carriers appear Red on-screen and on 
  radar (makes decoys more effective/confusing)
* Ball-carrier is a bigger red dot on radar
* Brighter in-game window outlines
* Can resize *.bm2 objects to whatever in-game dimensions you want

Chat
* Client keeps a chat buffer of chat, that can be stored to a file using 
  ?logbuffer (you can log chat that happens before you actually started logging)
* You can type smiles :) in public (but private smiles have to be inverted (: )
* ?away messages work across arenas/zones
* Can turn enter/leave messages on/off and/or display them in chat area, using 
  ?enter and ?leave
* What you type changes color (before you press enter) depending on message type
* Blinking cursor in chat area to indicate pending message
* Message history (ESC) displays more chat, and you can fly while it is on
* You can now use :: to cycle through the last five people to message you 
  (pressing : again cycles to next person in list - useful when carrying on 
  conversations with multiple people)
* Expanded Help Ticker.  Many more helpful messages for newbies
* Client remembers last five people who messaged you even after changing arenas 
  or changing zones
* ?go commands without a space are ignored (no more being mean to newbies with 
  ?godmode, only ?go dmode will work)
* Ctrl-Backspace deletes an entire line of text

Chat Window
* IRC-style chat window layout
* F2 Player List shown in alt-tab (so you can see who is in arena, what freq 
  they are on, etc. - just like in-game Player List)
* Chat display and Player List are resizable
* If disconnected, disconnection message appears in Chat Window (because it 
  was annoying being alt-tabbed and oblivious to the fact that you had been 
  disconnected the past 20 minutes)
* You can change arenas while in Chat Window (?go)
* You can change freqs while in Chat Window (=x)
* Private Message alarm beep sounds even when in Chat Window
* Double clicking on player name in player list will let you send them a private 
  message
* You can copy and paste text from chat window to other stuff

Other
* Each zone's stuff is stored to it's own subdirectory (news, maps, etc.).  You 
  can even put different sounds/graphics/shipsets in each zone directory and 
  Continuum will automatically use those for that zone.  Within each zone directory 
  you can create arena subdirectories and do the same.
* Banners stored to \banners, screenshots stored to \screenshots, game logs stored 
  to \logs, skins stored to \skins, graphics can be stored to \graphics, and sounds 
  can be stored to \sounds to help further reduce clutter in game directory
* The game has been rebuilt from the ground up, so the source code is ours.  This 
  means new features are easy to add and just around the corner.  More importantly, 
  should new cheats and cheat programs show up, the client can be easily updated 
  and distributed to counter them (read: no more cheaters!)
